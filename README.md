# 🛠️ SQL Server Express Setup Guide

This guide will help you install SQL Server Express, connect using SQL Server Management Studio (SSMS), and import/export databases.

---

## 📦 1. Install SQL Server Express
1. Download **SQL Server Express** from the official Microsoft website:  
   👉 [SQL Server Downloads](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)  
2. Run the installer and follow the setup wizard.  
3. Choose **SQL Server Express** during installation.  

---

## 💻 2. Find Your Computer Name & SQL Instance
After installation, you need your computer name and SQL instance:

1. Right-click **This PC** → **Properties** → find your **Computer Name**.
